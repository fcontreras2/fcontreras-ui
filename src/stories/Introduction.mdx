# @fcontreras2/ui

A modern, accessible, and fully customizable React component library built with **Tailwind CSS v4**.
Designed with a consistent API across all components — every component speaks the same language.

---

## Quick start

```bash
npm install @fcontreras2/ui
```

Import the styles once at the root of your app:

```tsx
import '@fcontreras2/ui/styles.css'
```

Use any component:

```tsx
import { Button, Input, Select } from '@fcontreras2/ui'

export function LoginForm() {
  return (
    <form>
      <Input label="Email" type="email" placeholder="you@example.com" />
      <Button type="submit">Sign in</Button>
    </form>
  )
}
```

## Design principles

| Principle | Description |
|---|---|
| **Consistent API** | Every component shares the same props pattern: `size`, `variant`, `classNames`, `error`, `helperText` |
| **Composable** | Components are primitives — combine them to build any UI |
| **Accessible** | ARIA roles, keyboard navigation, and focus management built-in |
| **Unstyled escape hatch** | Use `classNames` for granular token-level overrides without losing defaults |
| **Zero config** | No theme provider required. Just import and use |

## API conventions

All components follow the same prop patterns:

```tsx
// Size — shared across all components
size?: 'sm' | 'md' | 'lg'

// Variant — semantic color intent
variant?: 'default' | 'success' | 'warning' | 'danger' | 'info'

// Error & helper text — all form components
error?: string
helperText?: string

// Granular class overrides — every component
classNames?: {
  root?: string
  label?: string
  // ... component-specific slots
}
```

## Theming

The library uses a `primary` color palette that you can override in your CSS:

```css
@import 'tailwindcss';

@theme {
  --color-primary-50:  #eff6ff;
  --color-primary-100: #dbeafe;
  --color-primary-500: #3b82f6;
  --color-primary-600: #2563eb;  /* main brand color */
  --color-primary-700: #1d4ed8;
  /* ... */
}
```

Change `primary` to your brand color and all components update automatically.
